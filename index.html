PARALLEL TRACKS

Skills that grow with you

Programming is only one part of becoming a strong developer.

EN

General English

Build listening, speaking, reading, writing and vocabulary — not just technical English.

  • 15–30 min listening daily
  • Read content you actually enjoy
  • Practice speaking out loud
  • Learn vocabulary in context
  • Aim for B2 long term
AI

AI Literacy

Use AI as a teacher, reviewer and pair programmer without outsourcing your thinking.

  • Attempt before asking
  • Explain your hypothesis
  • Ask for hints before code
  • Review generated code critically
  • Never ship what you cannot explain
CR

Career

Start building your professional profile before you feel completely ready.

  • Keep GitHub clean
  • Write strong READMEs
  • Study real job descriptions
  • Build projects around recurring skills
  • Apply before you know everything
USEFUL PRINCIPLES

How to avoid wasting a year

01

One main language

Do not rotate between Java, Python, JavaScript and C# every two weeks.

02

30% learn, 70% do

Watching code feels productive. Writing your own code creates skill.

03

Errors are lessons

Read the stack trace, inspect state, form a hypothesis, then ask for help.

04

Monolith first

Learn to build one good application before distributing complexity.

05

Documentation wins

Progress from videos to docs and eventually to reading source code.

06

Optimize for independence

The goal is not knowing everything. It is knowing how to figure things out.

ONE LAST NOTE

Use this as a map, not as a rulebook.

Everyone learns differently. Skip what you already know, revisit what you need, and build things along the way.
